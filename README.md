# Сканер артикулов (Android 10–14, проверялось под Android 13)

Наводите камеру на ценник → «Распознать» → тап по нужному числу → артикул попадает в список.
Кнопка «Excel» сохраняет `Артикулы_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.xlsx` в папку «Загрузки» (Download) и предлагает «Поделиться».

## Как получить APK

### Вариант 1 — GitHub (без установки чего-либо на ПК)
1. Создайте пустой репозиторий на github.com (можно приватный).
2. Загрузите в него содержимое этой папки (кнопка «Add file → Upload files», перетащить все файлы и папки, включая `.github`).
   Если скрытая папка `.github` не загрузилась: «Add file → Create new file», имя `.github/workflows/build-apk.yml`, вставьте содержимое этого файла из архива.
3. Откройте вкладку **Actions** → сборка «Build APK» запустится сама (~5–7 мин).
4. В завершённой сборке внизу, в разделе **Artifacts**, скачайте `ArticleScanner-apk` (zip с `app-release.apk`).
5. Скиньте APK на телефон, откройте, разрешите «Установка из неизвестных источников».

### Вариант 2 — Android Studio
File → Open → папка проекта → Build → Build APK(s). Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Возможности
- Распознавание текста на устройстве (Google ML Kit, модель внутри APK — интернет не нужен).
- Поиск всех чисел на кадре, отсечение дат, цен и штрихкодов EAN (по контрольной цифре).
- Число со словом «арт.» и ближе к центру прицела предлагается первым (★).
- Подсказка в реальном времени: зелёная плашка «Артикул … ➕» — тап сразу добавляет.
- Долгое нажатие на вариант — исправить вручную; кнопка «Ввести вручную».
- Предупреждение о повторном артикуле.
- Список сохраняется при закрытии приложения; удаление по одному или очистка.
- Фонарик и фокус по тапу на экран.
- В xlsx все ячейки текстовые (артикулы не превращаются в 6,01E+09, ведущие нули сохраняются).
- Приложение «запоминает» длину и первые цифры ваших артикулов и поднимает похожие числа выше.
